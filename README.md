# ai-secretary-v1
# AI秘書 Ver.1

## コンセプト

スマートフォンを使っている間、ユーザーを継続的にサポートするAI秘書。

ユーザーが文字や音声で指示すると、AIが内容を理解し、必要な機能を選択してサポートする。

## Ver.1の主な機能

### 1. AIチャット

- AIと文字で会話できる

- 質問に回答できる

- 会話の文脈を維持する

### 2. 音声会話

- 音声でAIに話しかけられる

- AIが音声で回答する

- 将来的にイヤホンを使ったハンズフリー会話に対応する

- バックグラウンド動作はiOS/Androidの仕様に合わせて実装する

### 3. 画像分析

- 写真をAIに送信できる

- 写真の内容を分析できる

- 数学などの問題を写真から読み取れる

- 資料やプリントを分析できる

### 4. AI先生

- 勉強の質問に回答する

- 答えだけでなく解き方を説明する

- ヒントを出す

- 類題を作る

- 学習状況に合わせて教え方を変える

### 5. 文章生成

- メッセージ作成

- メール作成

- レポート作成

- 要約

- 発表原稿

- アイデア作成

### 6. 画像生成

- AIによる画像生成

- プレゼン用画像

- イラスト

- アイコンなどを作成

### 7. 通知AI

- 対応可能な通知を整理する

- 重要な通知を優先して知らせる

- 通知内容をユーザーに説明する

- 音声で通知を確認できる設計にする

### 8. メッセージアシスタント

- 対応可能な公式連携の範囲でメッセージ情報を扱う

- メッセージ内容を要約する

- 返信候補を作成する

- ユーザーの希望に合わせて返信文を変更する

例：

ユーザー：

「友達だから軽い感じで返信して」

AI：

「明日16時くらいなら大丈夫だよ！」

### 9. スケジュールアシスタント

- カレンダーの予定を確認する

- メッセージの内容と予定を照合する

- 予定が重なっている場合に知らせる

- 別の日や時間を提案する

- ユーザーの許可後に予定変更を実行する

### 10. 外部アプリ連携

公式APIやOSが提供する機能を利用して、対応可能なサービスと連携する。

例：

- Spotify

- カレンダー

- メモ

- ファイル

- その他対応サービス

ユーザー：

「Spotifyでお気に入りの曲を流して」

AI：

「了解」

↓

対応する公式連携を利用して再生する。

### 11. AI Action

AIがユーザーの目的を理解し、必要な機能を選択する。

例：

「明日の予定を確認して、友達との予定を入れられる時間を探して」

↓

1. カレンダーを確認

2. 空いている時間を探す

3. 候補を提示

4. ユーザーの確認

5. 必要に応じて予定を作成

## AIの基本フロー

ユーザー

↓

入力解析

↓

AI Core

↓

ユーザーの目的を理解

↓

必要な機能を選択

↓

Tool / APIを実行

↓

結果をAIが整理

↓

ユーザーへ回答

## 安全設計

AIが重要な操作を勝手に実行しない。

以下のような操作は基本的にユーザー確認を必要とする。

- メッセージ送信

- 予定の変更・削除

- 外部サービスへの投稿

- ファイル削除

- その他重要な操作

## 開発目標

まずVer.1では、

1. AIチャット

2. 画像分析

3. 音声入力

4. AIによる回答

5. 基本的なAI Action

を完成させる。

その後、

- 音声会話

- AIメモリー

- 通知AI

- カレンダー連携

- 外部アプリ連携

を追加する。

## 注意

LINE、Spotify、iOS、Androidなどの機能は、それぞれが提供する公式API・SDK・OS機能と利用規約の範囲内で実装する。
